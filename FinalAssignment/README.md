

This website is a personal photography site based on places I’ve photographed and ideas I want to keep developing. It is really a great idea for my future as well becuase even though is is smaller scale, there is a lot of useful things I have been able to learn that could help me create a portfolio. I focused on keeping the design simple so the images stand out, using a warm color palette and consistent layout across all pages.

While building this site, I learned how to combine Flexbox and Grid for different sections, and how small details like spacing, typography, and hover effects can make my site feel more complete. I added features like a responsive gallery, hover interactions, and a parallax section to add detail.

I’m most proud of how cohesive the site feels and how the gallery turned into something that feels more like a real collection instead of just a requirement.As I mentioned, I could see myself continuing to use this as a small portfolio and expanding it with more work in the future.

For my final adjustments, I plan to refine the page layouts, especially improving consistency in alignment. Some sections are centered while others are not, so I want to make those choices feel more intentional and balanced across the site, that is really the only aspect that is bugging me right now, as well as some of the captioning.
