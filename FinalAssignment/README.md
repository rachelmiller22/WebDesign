# Site Plan

My site plan for this website was to create a personal photography site based on places I have photographed and creative ideas I want to keep developing. The goal is for it to feel like a small portfolio that could continue to grow over time.

## Home Page

**Goal:** Introduce my photography, establish the overall mood, and guide users to other sections of the site.

### Structure
- **Navigation:** Logo (left), primary links to Home, Feature, Gallery, and Next Project centered, mobile toggle
- **Hero:** Large featured image to establish tone of  site
- **Lead-in:** Short paragraph explaining the inspiration behind my work
- **Main Content:** Card-based section showing different photography themes (coastal, natural forms, outdoor inspiration)
- **Supporting Content:** Parallax section to add depth and emphasize the theme
- **Call-to-Action:** Blog preview section linking to the Next Project page
- **Footer:** Copyright

---

## Feature Page

**Goal:** Highlight a featured photography story and give more context to my work.

### Structure
- **Navigation:** Same as Home (consistent across site)
- **Hero / Intro:** Page title (“Featured Story”)
- **Main Content:** Flexbox layout with images and text side-by-side
- **Supporting Content:** “Creative Direction” section explaining the mood and intent
- **Call-to-Action:** Links to view the gallery or read more
- **Footer:** Same as Home

---

## Gallery Page

**Goal:** Showcase my photography in a clean, organized, and interactive layout.

### Structure
- **Navigation:** Same as Home
- **Hero / Intro:** Page title (“Photo Gallery”) and short description
- **Main Content:** Grid-based image gallery with multiple photos
- **Supporting Content:** Hover overlays with titles for each image
- **Call-to-Action:** Encourages users to explore images more closely
- **Footer:** Same as Home

---

## Next Project Page

**Goal:** Reflect on my future direction and how I want to expand the site.

### Structure
- **Navigation:** Same as Home
- **Hero / Intro:** Page title (“My Next Website Idea”)
- **Main Content:** Blog-style layout with image and written reflection
- **Supporting Content:** Paragraphs describing future improvements (gallery, layout, overall feel)
- **Call-to-Action:** Encourages continued development of the site into a portfolio
- **Footer:** Same as Home
